Vendor marks for the dashboard rail, Add Provider catalog, and API-tab export rows.

Leave vendor artwork unmodified. `opencode.svg` is the third-party OpenCode
client mark (brand #211E1E). It is not a Benes logo. Do not replace it.

Used only on the API tab connect rows (not the provider rail):

- `pi.svg` — Pi favicon from `https://pi.dev/favicon.svg` (2026-08-02),
  project `earendil-works/pi`.
- `opencode.svg` — same file, reused as the OpenCode export-client mark.

Additional catalog marks are vendor logos from Lobe Icons, models.dev, Simple
Icons, or the vendor’s published favicon. Do not redraw them.

`../harness-icons/` holds mostly Benes-drawn harness glyphs. Two rows there
reuse vendor artwork instead of a house glyph: `dsh.svg` is the DeepSeek mark
from this directory, and `openclaw.svg` is the OpenClaw mark. Both are kept
exactly as the vendor published them; see `src/pages/harnesses/icons.ts` for
which harness renders which mark.

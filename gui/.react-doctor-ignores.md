# Why some React Doctor rules are off

`gui/react-doctor.oxlintrc.json` (generated by `gui/scripts/sync-react-doctor-oxlint-rules.ts`) sets these rules to `"off"`. This file is the reason list, not a second config. Turn a rule back on by removing it from the generator's off lists and re-running `npm run sync:react-doctor-oxlint`. Do not grow this list to hide a new finding.

Framework-specific rules (`react-native`, `nextjs`, `preact`, `tanstack-query`, `tanstack-start`), `defaultEnabled: false` rules, retired rules, and `REACT_DOCTOR_SCAN_RULES` (project-wide file scans that are no-ops under oxlint) are omitted from the generated fragment, not listed here.

## Dashboard debt (from the former `doctor.config.json`)

| Rule | Why it is off in this dashboard |
| --- | --- |
| `no-fetch-in-effect` | There is no React Query / SWR. Effects fetch with `AbortController`. The doctor prompt allows that for a small SPA without a data layer. |
| `no-giant-component` | Provider workspace and Models are multi-panel shells. Splitting them is its own refactor, not a doctor pass. |
| `prefer-useReducer` | Same shells. Moving many `useState` calls into reducers changes behaviour; it is not a mechanical cleanup. |
| `no-pass-live-state-to-parent`, `no-pass-data-to-parent`, `no-prop-callback-in-effect` | Codex pool dirty-flag lift is intentional until that flow is redesigned. |
| `no-derived-state`, `no-derived-state-effect` | The JSON editor keeps a `draft` that starts from `config` and then diverges. That is a controlled-draft pattern, not accidental derived state. |
| `only-export-components` | `QuotaBars` and `ProviderRail` keep tiny helpers next to the component. Fast Refresh tradeoff is accepted here. |
| `prefer-html-dialog` | Some overlays already use `<dialog>`. Remaining `role="dialog"` shells need a dedicated focus + open-state migration. |
| `js-hoist-intl` | Formatters take per-call options. A module-level cache would be incomplete. |
| `no-loading-flag-reset-outside-finally` | Many sites already reset inside `finally` with generation / `silent` guards the detector does not accept. Others keep loading across retries on purpose. |
| `rerender-state-only-in-handlers` | Dirty flags and modal ids drive control flow, not only JSX text. |
| `prefer-use-effect-event` | Optional React 19 API. Deferred so the tree does not mix patterns mid-cleanup. |
| `js-combine-iterations` | Two passes on small lists stay easier to read than a fused loop. |
